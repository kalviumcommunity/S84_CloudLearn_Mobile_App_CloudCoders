# Local Setup Checklist

1. Install Flutter SDK and verify with `flutter doctor`
2. Install Android Studio or Xcode tooling depending on target platform
3. Run `flutter pub get` in both repository root and `flut/`
4. Ensure Firebase config files are present in platform folders
5. Run `flutter analyze` before committing changes
6. Run `flutter test` to validate baseline behavior

This checklist is documentation-only.
